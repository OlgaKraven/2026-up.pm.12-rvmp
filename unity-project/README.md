# Кристальный маршрут

Учебный прототип для практики ПМ.12 «Программирование мобильных игр».

1. В Unity Hub добавьте корневую папку проекта, содержащую `Assets`, `Packages` и `ProjectSettings`, и откройте её в Unity 6.6 (6000.6.2f1). В репозитории это `unity-project`, после распаковки ZIP — `CrystalRoute`.
2. Откройте сцену `Assets/Scenes/Main.unity`.
3. Нажмите Play.
4. Управляйте стрелками, WASD или экранными кнопками.
5. Соберите пять кристаллов, избегая красных препятствий, затем войдите в зелёный портал.

`R` перезапускает игру. Клавиши `F6`-`F9` предназначены для демонстрации преподавателем и подготовки снимков.

Это общий демонстрационный пример сбора. Правило своего варианта подключайте по методичке; `MechanicModels.cs` содержит учебные модели для такого расширения.
