# УП ПМ.12 «Программирование мобильных игр»

Комплект версии 2.0 для группы ОКИПс-22309МО: общее задание, 30 вариантов, методичка с рабочей основой движения и последующим расширением, демонстрационный «Кристальный маршрут» и общий Markdown-шаблон отчёта.

[Открыть учебный сайт](https://olgakraven.github.io/2026-up.pm.12-rvmp/)

## Запуск демонстрации

Откройте `unity-project` через Unity Hub в Unity 6000.6.2f1. Откройте `Assets/Scenes/Main.unity`, нажмите Play, выберите Game 16:9. Управление — WASD, стрелки и экранные кнопки. Соберите пять предметов и войдите в портал; три повреждения дают поражение. R и кнопка результата запускают игру заново. F6–F9 — служебные команды; проверки условий выполняются игровыми действиями.

## Источники и сборка

Учебное содержание находится в `content/course.json`, финальный код — в `unity-project/Assets/Scripts`, учебные промежуточные фрагменты — в `tutorial`. Генератор читает фрагменты из исходников; не нужно вручную переносить их в PDF.

После установки зависимостей из `requirements.txt` в имеющуюся среду выполните `python scripts/build.py` и `python scripts/check.py`. Это черновая сборка. Выпуск `--release` требует локальную запись реального выполнения, проверки вариантов, визуального просмотра и сверки с аудитом с актуальной контрольной суммой содержания; служебные записи не публикуются.

Проверенные файлы `site/` публикуются целиком. GitHub Actions проверяет уже подготовленный выпуск и размещает его, не выдавая новую непроверенную сборку за выпуск. Изменение содержания требует пересборки и повторной проверки.

В загрузках находятся PDF предметных областей и методички, общий `report-template.md`, демонстрационный ZIP и исходники. Android-сборка и работа на телефоне требуют отдельной проверки и не подтверждаются запуском в редакторе.
