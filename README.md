# УП ПМ.12 «Программирование мобильных игр»

Учебно-методический комплект первой практики для группы ОКИПс-22309МО. Один проект объединяет:

- обязательное задание в PDF A4, альбомная ориентация;
- 30 содержательно различных вариантов в шести группах механик;
- подробную инструкцию с микро-шагами, проверками, снимками и полным кодом;
- проверенный Unity-прототип «Кристальный маршрут»;
- сайт преподавателя для обзорного вебинара.

## Готовые материалы

После сборки каталог `site/` содержит три раздела: «Задание», «Инструкция и образец», «Предметные области».

В `site/downloads/` создаются:

- `assignment.pdf` — обязательное задание и 30 вариантов;
- `guide.pdf` — подробная пошаговая инструкция;
- `CrystalRoute-UnityProject.zip` — готовый проект без служебных папок Unity;
- шесть исходных файлов C#.

Студентам достаточно передать `assignment.pdf`. Инструкцию и исходные файлы преподаватель выдаёт по своему решению. Репозиторий и сайт предназначены для хранения и демонстрации преподавателем.

## Запуск прототипа

1. Откройте папку `unity-project` в Unity 6.6 (6000.6.2f1).
2. Откройте `Assets/Scenes/Main.unity`.
3. Нажмите Play.
4. Управляйте стрелками, WASD или экранными кнопками.
5. Соберите пять кристаллов и войдите в зелёный портал.

Клавиша `R` начинает заново. Для демонстрации: `F6` добавляет кристалл, `F7` показывает победу, `F8` — поражение, `F9` сохраняет снимок Game View.

## Сборка сайта и PDF

```sh
python -m pip install -r requirements.txt
python scripts/build.py --release
python scripts/check.py
python -m http.server 8000 --directory site
```

Единственный источник учебного текста — `content/course.json`. Код хранится в `unity-project/Assets/Scripts`; сборщик вставляет актуальные диапазоны строк в сайт и PDF, копирует исходники и формирует ZIP. Автоматическая проверка контролирует 30 уникальных вариантов, полноту листингов, внутренние ссылки, размеры PDF и состав публикации.
