# Правила проекта практики

- Единственный источник учебного текста — `content/course.json`.
- Единственный источник программного кода — файлы в `unity-project/Assets/Scripts`; сайт, PDF и загрузки получают код из них.
- Одна практика — одно задание с этапами. Связь с другими практиками указывается только при необходимости.
- На сайте остаются три раздела: «Задание», «Инструкция и образец», «Предметные области».
- Не создавать раздел «Преподавателю», отдельный повторяющий образец, параллельный генератор или копию JSON.
- Одно действие — один микро-шаг и один видимый результат. Термин объяснять до применения. После блока действий добавлять проверку и типичную ошибку.
- Не упоминать способности студентов.
- Все 30 вариантов должны содержательно различаться и требовать изменения программного правила.
- PDF: A4, альбомный формат, читаемый полный код, номера страниц и реальные статичные снимки без анимации.
- Служебные папки Unity (`Library`, `Temp`, `Logs`, `obj`, `UserSettings`, `Build`) не коммитить и не включать в ZIP.
- Перед публикацией: проверить проект в Unity, выполнить `python scripts/build.py --release`, `python scripts/check.py`, отрисовать и просмотреть оба PDF.
